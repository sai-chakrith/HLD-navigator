# Powertrain architecture
The Engine component provides the TorqueInterface interface to the Cluster component and receives the BrakeInterface interface from the ABS component.
The TorqueInterface interface carries the Torque signal. The BrakeInterface interface carries the Brake signal.
The Torque signal has type uint16 and unit Nm. The Brake signal has type boolean.

## Ports
| Port Name | Component | Interface | Port Kind | Data Type |
| --- | --- | --- | --- | --- |
| TorqueOut | Engine | TorqueInterface | P-Port | uint16 |
| TorqueIn | Cluster | TorqueInterface | R-Port | uint32 |
| BrakeOut | ABS | BrakeInterface | P-Port | boolean |
| BrakeIn | Engine | BrakeInterface | P-Port | boolean |
